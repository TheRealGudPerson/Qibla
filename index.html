Sun-position guide

Set a location to calculate the sun's position.

Sun azimuth is calculated from location, date, and time. If the sun is visible, compare its real-world direction with the bearing shown above. This guide does not detect where you are facing. Do not look directly at the sun.

Advanced: external heading reference

This app does not read the phone magnetometer. If you have a separate, trusted instrument that reports heading relative to true north, enter it here to calculate the Qibla angle relative to that heading. Do not enter a magnetic-compass heading unless corrected for magnetic declination.

Qibla bearing is calculated relative to true north. Map tiles © OpenStreetMap contributors. City search uses OpenStreetMap Nominatim. Map and city search require internet. No heading sensors are used.
